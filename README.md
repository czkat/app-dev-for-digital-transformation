### Prototype:

The prototype in folder "WinFormsApp1" showcases usability of the User Interface designed for customers that are ready for digital transformation of their factories especially in CNC machining industry. The design intent is to nudge industry partners into digital transformation by creating smart cost monitoring.
This could be achieved by probing status data in real time and visualising key aspects for reporting.
